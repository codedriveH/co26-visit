# 순회 방문 신청

순회 방문 기간에 전도인들이 오전 봉사, 오후 봉사, 저녁 식사 후대를 스마트폰으로 신청하는 웹사이트입니다.

- **전도인**: 카카오톡으로 받은 링크를 열어 이름과 휴대폰 번호로 들어간 뒤, 참여할 수 있는 칸을 모두 눌러 신청합니다.
- **장로**: 구글 시트의 "신청현황" 탭에서 신청 내용을 보고 체크박스로 배정합니다. 사용법은 [장로용 사용 안내](장로용%20사용%20안내.md)에 있습니다.

| 구성 | 위치 | 설명 |
|---|---|---|
| 화면 | `docs/` | GitHub Pages에 올리는 정적 사이트 (HTML, CSS, JavaScript) |
| 서버 | `apps-script/` | 구글 시트에 붙이는 Apps Script. 웹앱 API와 시트 메뉴 |
| 자료 | 구글 시트 | 명단, 일정, 신청 내용이 모두 여기에만 저장됩니다 |

> **개인정보 주의**: 이 저장소는 공개됩니다. 이름, 전화번호 같은 개인정보는 저장소에 절대 올리지 말고 구글 시트에만 두세요. 전화번호는 시트에도 원문이 아니라 암호화된 값(해시)으로 저장됩니다.

## 설치 순서

처음 한 번만 하면 됩니다. 30분 정도 걸립니다.

### 1. 구글 시트 만들기와 Apps Script 연결

1. 사용할 구글 시트를 엽니다. (새로 만들어도 되고, 이미 만든 시트를 써도 됩니다.)
2. 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다. 새 창에 스크립트 편집기가 열립니다.
3. 왼쪽 파일 목록에 `Code.gs` 하나가 있습니다. 안의 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 복사해 붙여 넣습니다.
4. 파일 목록 위의 **+ → 스크립트**를 눌러 아래 이름으로 파일을 하나씩 만들고, 같은 이름의 파일 내용을 붙여 넣습니다. (이름에 `.gs`는 자동으로 붙으니 `Utils`처럼 앞부분만 입력합니다.)
   - `Utils`, `Setup`, `Api`, `Status`, `Sync`, `Recommend`, `TestData`
5. 왼쪽 톱니바퀴(**프로젝트 설정**)를 눌러 **"appsscript.json" 매니페스트 파일을 편집기에 표시**를 체크합니다. 편집기로 돌아가 `appsscript.json`을 열고 이 저장소의 `apps-script/appsscript.json` 내용으로 바꿉니다.
6. 디스크 모양의 **저장** 버튼을 누릅니다.

> **더 쉬운 방법**: 파일 8개를 따로 만드는 대신 [`한번에-붙여넣기/Code.gs`](한번에-붙여넣기/Code.gs) 하나만 `Code.gs`에 통째로 붙여 넣어도 똑같이 동작합니다. 이 경우 3~4번은 건너뛰고, 5번(`appsscript.json`)과 6번(저장)만 하면 됩니다.

### 2. 초기 설정 실행과 권한 승인

1. 구글 시트 창으로 돌아가 **새로 고침**(F5)합니다. 잠시 뒤 위쪽 메뉴에 **순회방문 관리**가 생깁니다.
2. **순회방문 관리 → 초기 설정**을 누릅니다.
3. 처음에는 "승인 필요" 창이 뜹니다. **확인 → 내 구글 계정 선택 → 고급 → (프로젝트 이름)(으)로 이동 → 허용** 순서로 누릅니다.
   - "Google에서 확인하지 않은 앱"이라는 경고는 내가 직접 만든 스크립트라서 나오는 것이니 걱정하지 않으셔도 됩니다.
4. 승인 뒤에는 실행이 안 된 상태이므로 **초기 설정**을 한 번 더 누릅니다.
5. "초기 설정이 끝났습니다" 창이 뜨면 탭 8개(명단, 일정, 신청, 설정, 신청현황, 추천결과, 전도인별, 로그)가 만들어진 것입니다.

초기 설정은 여러 번 눌러도 입력해 둔 자료를 지우지 않습니다.

### 3. 솔트 설정

솔트는 전화번호를 암호화할 때 섞는 비밀 값입니다. **초기 설정을 실행할 때 자동으로 만들어지므로 따로 할 일은 없습니다.**

- 확인하려면: 스크립트 편집기 → 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성**에 `SALT`가 있습니다.
- 직접 정하고 싶다면 그 값을 고치면 됩니다. 단, **명단의 전화번호를 해시로 바꾸기 전에** 고쳐야 합니다. 나중에 바꾸면 모든 사람이 로그인하지 못하게 되며, 그때는 명단에 전화번호를 다시 입력하고 해시 변환을 다시 해야 합니다.
- 솔트 값은 다른 사람에게 알려 주거나 저장소에 올리지 마세요.

### 4. 명단, 일정, 마감일 입력

1. **명단** 탭: 이름, 전화번호, 성별(형제/자매)을 입력합니다. 전화번호는 B열에 `010-1234-5678`처럼 그대로 적습니다.
2. **순회방문 관리 → 전화번호 해시 변환**을 누릅니다. B열이 긴 영문·숫자 값으로 바뀌면 된 것입니다. 사람을 추가할 때마다 다시 누르면 새로 입력한 번호만 바뀝니다.
   - 이름이 같은 분이 있으면 `김철수(대)`, `김철수(소)`처럼 다르게 적어 주세요. 그분들은 로그인할 때도 그 이름으로 입력해야 합니다.
3. **일정** 탭: 계획표를 한 줄에 한 칸씩 입력합니다.

   | 칸ID | 날짜 | 요일 | 항목 | 팀 | 시간 | 장소 | 필요인원 | 열림여부 | 추천성별 |
   |---|---|---|---|---|---|---|---|---|---|
   | 1229-AM-A | 2026-12-29 | | 오전봉사 | A | 9:30 | 왕국회관 | 4 | ☑ | |
   | 1229-AM-B | 2026-12-29 | | 오전봉사 | B | 9:30 | ○○ 형제 댁 | 4 | ☑ | |
   | 1229-LN | 2026-12-29 | | 점심식사 | 공통 | | | 1 | ☑ | |
   | 1229-DN | 2026-12-29 | | 저녁식사 | 공통 | 18:00 | | 1 | ☑ | |

   - **칸ID**는 서로 겹치지만 않으면 됩니다. `날짜-AM/PM/DN-팀`처럼 지으면 알아보기 쉽습니다. 신청을 받기 시작한 뒤에는 칸ID를 바꾸지 마세요.
   - **요일**은 비워 두면 자동으로 계산됩니다.
   - **항목**은 오전봉사, 점심식사, 오후봉사, 저녁식사 중 하나입니다.
   - **팀**에는 A, B를 적거나, 방문하는 분마다 칸을 따로 두려면 그분의 이름을 적습니다. 화면에는 A, B는 "A팀", "B팀"으로, 이름은 그대로 보입니다. 모두 함께하는 칸은 `공통`이라고 적습니다.
   - **시간**이 다르면 화면에서 시간별로 묶여 보입니다. 같은 봉사 안에서 교대가 있으면 `9:45`, `10:45`처럼 줄마다 다른 시간을 적습니다.
   - **추천성별**에 형제 또는 자매를 적으면 자동 추천이 그 성별의 신청자만 추천합니다. 비워 두면 가리지 않습니다. (전도인의 신청 자체는 막지 않습니다.)
   - **필요인원**은 배정할 인원입니다. 저녁 식사는 대접할 가정 수(보통 1)를 적습니다.
   - **열림여부**를 체크한 칸만 전도인이 신청할 수 있습니다.
4. **설정** 탭: `신청마감일시`에 `2026-12-20 21:00`처럼 입력합니다. 이 시각이 지나면 신청과 취소가 막힙니다.

### 5. 트리거 설치 (자동 갱신, 배정 동기화)

시트 메뉴에서 두 가지를 한 번씩 누릅니다.

- **순회방문 관리 → 자동 갱신 켜기**: 10분마다 신청현황 탭을 새로 그립니다.
- **순회방문 관리 → 배정 동기화 트리거 설치**: 신청현황 탭에서 체크박스를 누르면 신청 탭의 상태가 함께 바뀌게 합니다.

두 가지 모두 **시트 주인(웹앱을 배포할 사람)의 계정**으로 눌러 주세요.

### 6. 웹앱 배포와 주소 복사

1. 스크립트 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. "유형 선택" 옆 톱니바퀴를 눌러 **웹 앱**을 고릅니다.
3. 다음과 같이 정합니다.
   - 설명: 아무 말이나 (예: `첫 배포`)
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
5. 확인: 그 주소를 브라우저 주소창에 붙여 넣어 열었을 때 `{"ok":true,"message":"순회 방문 신청 API가 동작 중입니다."}`가 보이면 정상입니다.

### 7. config.js에 주소 넣기

`docs/config.js`를 열어 따옴표 안에 방금 복사한 주소를 붙여 넣습니다.

```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/여기에_복사한_주소/exec'
};
```

GitHub 웹사이트에서 바로 고칠 수 있습니다. 저장소에서 `docs/config.js`를 열고 연필 모양 버튼 → 수정 → **Commit changes**를 누르면 됩니다.

### 8. GitHub 저장소와 Pages 켜기

1. 이 코드를 GitHub 저장소에 올립니다. 저장소는 **Public(공개)**이어야 무료로 Pages를 쓸 수 있습니다.
2. 저장소의 **Settings → Pages**로 갑니다.
3. **Source**는 `Deploy from a branch`, **Branch**는 `main`, 폴더는 `/docs`를 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. (`https://아이디.github.io/저장소이름/`)
5. 이 주소를 카카오톡으로 전도인들에게 보내면 됩니다.

### 9. 테스트해 보기

실제 명단이 없어도 시험해 볼 수 있습니다.

1. **순회방문 관리 → 테스트 데이터 넣기**를 누릅니다. 가짜 명단 12명, 가짜 일정 20칸, 가짜 신청이 들어갑니다.
2. 스마트폰으로 Pages 주소를 열어 이름 `김하늘(테스트)`, 전화번호 `010-0000-0001`로 들어가 신청과 취소를 해 봅니다.
3. 시트에서 **신청현황 새로고침**을 눌러 방금 한 신청이 보이는지, 체크박스를 눌렀을 때 신청 탭의 상태가 "배정"으로 바뀌는지 확인합니다.
4. 다 보셨으면 **순회방문 관리 → 테스트 데이터 지우기**를 꼭 눌러 주세요. `(테스트)`가 붙은 이름과 `TEST-`로 시작하는 칸만 지워지며 실제 자료는 그대로 남습니다.

## 코드를 고친 뒤 다시 배포할 때

Apps Script 코드는 저장만 해서는 웹앱에 반영되지 않습니다. **새 배포를 만들면 주소가 바뀌어** config.js도 다시 고쳐야 하므로, 반드시 아래 방법으로 하세요.

1. 스크립트 편집기에서 **배포 → 배포 관리**를 누릅니다.
2. 왼쪽에서 기존 배포를 고르고 오른쪽 위 **연필(수정)** 버튼을 누릅니다.
3. **버전**을 **새 버전**으로 바꿉니다.
4. **배포**를 누릅니다. 주소는 그대로이고 내용만 새것으로 바뀝니다.

`docs/` 안의 화면 파일은 GitHub에 올리기만 하면 1~2분 뒤 자동으로 반영됩니다. 카카오톡 안에서 예전 화면이 계속 보이면 링크를 다시 눌러 열어 보세요.

## 계획표를 일정 탭 형식으로 바꾸기

계획표가 표로 되어 있다면 아래 규칙으로 한 줄씩 옮기면 됩니다.

- 신청받을 자리 하나가 한 줄입니다. 예를 들어 네 분이 각각 4교대로 봉사하면 그 봉사는 16줄이 됩니다.
- 모두 함께하는 시간(식사 등)은 팀을 `공통`으로 해서 한 줄만 적습니다.
- 집회, 장로 모임처럼 신청을 받지 않는 시간은 적지 않습니다.

## 시트 탭 설명

| 탭 | 용도 | 직접 고쳐도 되나요? |
|---|---|---|
| 명단 | 로그인할 수 있는 사람 | 예 (전화번호는 입력 후 해시 변환) |
| 일정 | 신청받을 칸 | 예 |
| 신청 | 모든 신청과 배정 상태의 **원본** | 급할 때만. 상태 열을 직접 고칠 수 있습니다 |
| 설정 | 신청마감일시, 결과공개여부 | 예 |
| 신청현황 | 시간대별 신청자와 배정 체크박스 | 체크박스만 |
| 추천결과 | 자동 추천 미리보기 | 아니요 |
| 전도인별 | 사람별 신청 수와 배정 수 | 아니요 |
| 로그 | 누가 언제 신청·취소·배정했는지 | 아니요 |

## 자주 묻는 것

- **"이름이나 휴대폰 번호가 명단과 다릅니다"라고 나와요.** 명단 탭에 그 이름이 있는지, 전화번호를 해시로 변환했는지 확인해 주세요. 번호가 바뀐 분은 B열을 지우고 새 번호를 적은 뒤 해시 변환을 다시 누르면 됩니다.
- **5번 틀려서 막혔어요.** 10분 뒤에 풀립니다.
- **체크박스를 눌러도 신청 탭이 안 바뀌어요.** "배정 동기화 트리거 설치"를 눌렀는지 확인해 주세요.
- **신청현황 탭을 고치려 하면 경고가 떠요.** 체크박스 외의 칸을 실수로 고치지 않게 해 둔 것입니다. 자료를 고치려면 신청 탭에서 고친 뒤 "신청현황 새로고침"을 누르세요.
- **하루 사용량 제한이 있나요?** 개인 구글 계정 기준으로 회중 한 곳이 쓰기에는 충분합니다.

## 보안에 관해

- 화면은 토큰만 저장하며, 서버는 요청마다 토큰으로 본인을 확인합니다. 화면이 보내는 이름은 믿지 않습니다.
- 다른 사람의 이름이나 신청 내용은 화면으로 보내지 않고 칸별 인원 수만 보냅니다.
- 결과를 공개하기 전에는 본인의 배정 여부도 화면에 보내지 않습니다.
- 휴대폰 번호는 누구나 알 수 있는 정보이므로 은행 수준의 보안은 아닙니다. 봉사 신청 용도에 맞는 간단한 본인 확인입니다.
